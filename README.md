# Guildmaster

A single-page browser game. No build step. `index.html` is the whole game.

## Deploy to Vercel

1. Install the CLI once: `npm i -g vercel`
2. In this folder run: `vercel` (accept the defaults, framework "Other", no build command)
3. For the production URL run: `vercel --prod`

Or push this folder to GitHub and import the repo at https://vercel.com/new.
Leave Framework Preset as "Other" and the build and output settings empty.
